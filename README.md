# Dossier de passation — Portfolio Anthony Mure

## Comment l'utiliser

1. Dézippe ce dossier là où tu veux créer le projet (par exemple `~/Sites/portfolio-anthony-mure`).
2. Ajoute tes images dans un sous-dossier `images/` (photos, affiches, portrait, vignettes, boucles vidéo), rangées par projet si possible.
3. Ouvre Claude Code dans ce dossier et écris par exemple :
   > Lis CLAUDE.md et BRIEF.md, puis construis le site à partir des maquettes. Commence par la Home et Work.

Claude Code lit `CLAUDE.md` automatiquement à l'ouverture du dossier.

## Contenu

- `CLAUDE.md` : instructions pour Claude Code (stack, règles).
- `BRIEF.md` : cahier des charges complet.
- `maquettes/` : les 9 maquettes validées + `LIRE-MOI.md`.
- `design/tokens.css` : couleurs, typo, arrondis, espacements.
- `design/motifs/` : étoiles, vague, soulignement, badge, flèche (SVG).
- `content/projects.json` : la liste des projets.
- `docs/brief-arborescence-original.md` : ton brief de départ.

## Ce qu'il reste à préparer

- Les images et vidéos (showreel, boucles de 3–5 s pour le survol, affiches, portrait).
- Le nom du bar, les années, clients et rôles des projets.
- Les prix, le délai de réponse, le texte About, les logos clients, les mentions légales.
- Tes liens Instagram / YouTube / Vimeo définitifs.
